
# FlexAssays

<!-- badges: start -->
<!-- badges: end -->

The goal of FlexAssays is to organize multiple matrix-like assays with 
different dimensions.

## Installation

You can install the development version of FlexAssays from 
[GitHub](https://github.com/) with:

``` r
# install.packages("devtools")
devtools::install_github("ycli1995/FlexAssays")
```
